Neovim tooling

Lua · scholar.nvim · workspace-config.nvim

scholar.nvim is a Neovim plugin for taking notes on academic papers. You select a DOI in the editor, and it pulls the paper's title, authors, journal, year and full reference list from CrossRef. Then it creates a Markdown note from a template you can customize. I built it so reading papers and keeping notes on them could happen in the editor I already use, without copying citation details by hand.

workspace-config.nvim gives each project its own Neovim setup through a .nvimrc.lua file in the project root. It installs language servers through Mason and applies project-specific LSP settings. It can also set up debug adapters, filetype options, keymaps and commands. I built it because one global config never fit every project, and I wanted each repo to carry its own editor, LSP and debugging setup.
